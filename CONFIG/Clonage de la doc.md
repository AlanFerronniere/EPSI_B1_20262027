Il faut avoir installé sur votre machine :
- git (https://git-scm.com/)
- Obsidian (https://obsidian.md/)

Pour cloner la doc sur votre machine, ouvrez un terminal sur votre machine (clic droit sur le bouton windows > terminal)
Dans ce terminal, positionnez vous dans le dossier dans lequel vous voulez ranger la documentation. Par exemple :

```sh
cd "C:\Users\ferro\Desktop\Cours EPSI\Cours Alan"
```

Ca ressemble à ça :
![[Pasted image 20260922174107.png]]

Puis clonez le dépôt git de la doc avec cette commande :

```sh
git clone https://github.com/AlanFerronniere/EPSI_B1_20262027.git
```

Ca doit faire ça :
![[Pasted image 20260922174204.png]]

Ensuite dans Obsidian, vous pouvez "ouvrir un dossier comme un coffre" en allant chercher ce dossier `C:\Users\ferro\Desktop\Cours EPSI\Cours Alan\EPSI_B1_20262027`

![[Pasted image 20260922174232.png]]


Dans Obsidian vous pouvez ensuite dans les paramètres (le petit engrenage en bas à gauche) activer les modules complémentaire et installer le module git
![[Pasted image 20260922174358.png]]

Ca vous permet d'avoir ce nouvel outil : ![[Pasted image 20260922174445.png]]
Qui ouvre cette fenêtre d'outil : ![[Pasted image 20260922174528.png]]

Pour mettre à jour des choses quand j'ai ajouté des cours dans la doc, vous n'avez plus qu'à cliquer sur Pull ![[Pasted image 20260922174607.png]]

Voilà c'est tout.
