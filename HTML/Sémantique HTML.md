# La sémantique HTML

## Définition
La sémantique HTML fait référence à l'utilisation de balises HTML qui décrivent clairement le contenu qu'elles contiennent. Contrairement aux balises non sémantiques comme `<div>` et `<span>`, les balises sémantiques fournissent des informations sur la nature du contenu, ce qui améliore la lisibilité du code, l'accessibilité et le référencement.
En écrivant de l'HTML il est important de choisir les balises qui correspondent le mieux au contenu que vous souhaitez structurer.
## Importance de la sémantique HTML
1. **Accessibilité** : Les lecteurs d'écran et autres technologies d'assistance peuvent mieux interpréter le contenu lorsqu'il est structuré avec des balises sémantiques.
2. **SEO (Search Engine Optimization)** : Les moteurs de recherche utilisent la structure sémantique pour comprendre le contenu d'une page, ce qui peut améliorer le classement dans les résultats de recherche.
3. **Maintenance du code** : Un code bien structuré est plus facile à lire et à maintenir pour les développeurs.
## Les balises classiques importantes dans la sémantique HTML

- `<h1>` à `<h6>` : Balises de titres, où `<h1>` est le titre principal et `<h6>` le titre le moins important.
- `<p>` : Balise de paragraphe.
- `<a>` : Balise de lien hypertexte.
- `<ul>`, `<ol>`, `<li>` : Balises pour les listes non ordonnées et ordonnées.
- `<img>` : Balise pour insérer des images.
- `strong` : Balise pour indiquer un texte important (généralement rendu en gras).
- `em` : Balise pour indiquer un texte emphatique (généralement rendu en italique).
- `blockquote` : Balise pour citer un passage de texte.
- `code` : Balise pour indiquer un fragment de code informatique.
- `pre` : Balise pour afficher du texte préformaté.
## Balises HTML sémantiques courantes

- `<header>` : Définit l'en-tête d'une page ou d'une section.
- `<nav>` : Définit une section de navigation.
- `<main>` : Définit le contenu principal d'un document.
- `<section>` : Définit une section générique d'un document.
- `<article>` : Définit un contenu autonome, comme un article de blog ou une nouvelle.
- `<aside>` : Définit un contenu en marge, comme une barre latérale.
- `<footer>` : Définit le pied de page d'une page ou d'une section.
- `<figure>` : Définit un contenu illustratif, comme une image avec une légende.

## Balises non sémantiques

- `<div>` : Utilisé comme conteneur générique sans signification particulière.
- `<span>` : Utilisé pour styliser une partie de texte sans signification particulière.
- `<b>` : Utilisé pour rendre le texte en gras sans indiquer d'importance.
- `<i>` : Utilisé pour rendre le texte en italique sans indiquer d'emphase.
- `<u>` : Utilisé pour souligner le texte sans indiquer d'importance. (rarement utilisé parce que les liens sont souvent soulignés)
