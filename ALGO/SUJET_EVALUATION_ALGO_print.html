Mise en situation : À la grande chatterie, le distributeur automatique de lait tiède a été automatisé. Pour que chaque chaton obtienne sa ration de lait dans sa coupelle, il présente son collier d'identification avec une chaîne complexe gravée.

Votre mission est de concevoir l'algorithme qui calcule la ration de chaque chaton et trouve la valeur de déverrouillage finale de la machine.

TEST WEB https://www.latetedanslephp.fr/chatons
RENDU https://forms.gle/nX11yspbzBoUuVvs5
Le fichier d'entrée (100 lignes) est fourni séparément sur votre espace de cours.
1. Partie 1 — Calcul de la Ration de Lait Standard Objectif Déverrouillage

Règle de calcul : Pour chaque chaton, sa ration de lait (en ml) est obtenue en multipliant le nombre total de chiffres présents dans son collier par la somme de tous ces chiffres :

Ration de Lait (ml) = (Nombre total de chiffres) × (Somme des chiffres)

• S'il n'y a aucun chiffre dans la chaîne du collier, la ration est égale à 0 ml.

Collier Chaton (Input) Chiffres Présents Nb Chiffres Somme Chiffres Ration Calculée
Garfield-7b-3 7, 3 2 7 + 3 = 10 2 × 10 = 20 ml
Moustic22-Patte4-1 2, 2, 4, 1 4 2 + 2 + 4 + 1 = 9 4 × 9 = 36 ml
Flocon-005 0, 0, 5 3 0 + 0 + 5 = 5 3 × 5 = 15 ml
Minou-Gris (aucun chiffre) 0 0 0 ml
Exemple sur ces 4 lignes — Valeur de déverrouillage finale : 20 + 36 + 15 + 0 = 71 ml
Consignes pour la Partie 1 :
  • Lisez l'intégralité du fichier d'entrée fourni contenant les colliers.
  • Pour chaque ligne, isolez les chiffres, comptez-les et additionnez-les.
  • Multipliez le nombre de chiffres par leur somme pour obtenir la ration de la ligne.
  • Accumulez toutes les rations dans un total général.
  • Testez immédiatement votre total sur la plateforme web de validation !

2. Partie 2 — Sécurité Renforcée & Régime Personnalisé Sécurité Niveau 2

Mise à jour du distributeur : Afin d'adapter les apports au métabolisme des chatons, le distributeur filtre désormais les chiffres selon la nature du premier caractère du nom :

• Nom commençant par une LETTRE : on ne prend en compte que les chiffres pairs (0, 2, 4, 6, 8) :

Ration = (Nombre de chiffres pairs) × (Somme des chiffres pairs)

• Nom commençant par un CHIFFRE : on ne prend en compte que les chiffres impairs (1, 3, 5, 7, 9) :

Ration = (Nombre de chiffres impairs) × (Somme des chiffres impairs)

• S'il n'y a aucun chiffre correspondant au filtre sur la ligne, la ration est de 0 ml.

Collier Chaton Chiffres Filtrés Nb Filtrés Somme Filtrée Ration Partie 2
Garfield-7b-3 Lettre → pairs : aucun 0 0 0 ml
Moustic22-Patte4-1 Lettre → pairs : 2, 2, 4 3 2 + 2 + 4 = 8 3 × 8 = 24 ml
Flocon-005 Lettre → pairs : 0, 0 2 0 + 0 = 0 2 × 0 = 0 ml
1-Minou-Gris Chiffre → impairs : 1 1 1 1 × 1 = 1 ml
02-Minette-7 Chiffre → impairs : 7 1 7 1 × 7 = 7 ml
💡 UN INDICE (Parce que je suis gentil)

En PHP, la fonction ctype_digit() permet de tester facilement si un caractère est un chiffre :

ctype_digit('5'); // retourne true
ctype_digit('a'); // retourne false
ctype_digit('-'); // retourne false
📖 Documentation officielle : https://www.php.net/manual/fr/function.ctype-digit.php
