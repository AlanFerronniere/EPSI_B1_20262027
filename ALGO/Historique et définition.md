# Historique
L'algorithmique est une discipline qui remonte à l'Antiquité, avec des contributions majeures de mathématiciens comme Euclide et Al-Khwarizmi. Le terme "algorithme" dérive du nom d'Al-Khwarizmi, mathématicien perse du IXe siècle.
## Turing et les premiers ordinateurs
Alan Turing, souvent considéré comme le père de l'informatique moderne, a formalisé le concept d'algorithme avec la machine de Turing dans les années 1930. Cette abstraction a jeté les bases de la théorie de la computation.

Les premiers ordinateurs programmables dans les années 1940, comme l'ENIAC, ont permis l'exécution pratique des algorithmes.
# Qu'est-ce qu'un algorithme ?
Un **algorithme** est une suite d'instructions claires, finies et non ambiguës, conçue pour résoudre un problème spécifique ou pour accomplir une tâche. Pensez-y comme à une recette de cuisine : chaque étape doit être suivie dans le bon ordre pour obtenir le plat désiré.

**Les propriétés d'un algorithme :**
- **Fini :** Il doit se terminer après un nombre fini d'étapes.
- **Défini :** Chaque étape doit être décrite de manière précise et sans ambiguïté.
- **Entrée :** Il peut prendre zéro ou plusieurs données en entrée.
- **Sortie :** Il doit produire au moins un résultat en sortie.
- **Efficace :** Il doit être réalisable en un temps raisonnable.
- **Général :** Il doit être applicable à une classe de problèmes, pas seulement à un cas spécifique.
- **Lisible :** Il doit être compréhensible par les humains.
- **Modulaire :** Il doit pouvoir être divisé en sous-parties ou fonctions.
- **Correct :** Il doit produire les résultats attendus pour toutes les entrées valides.
- **Optimisé :** Il doit utiliser les ressources (temps, mémoire) de manière efficace.
- **Itératif :** Il doit pouvoir répéter certaines étapes si nécessaire.
- **Adaptable :** Il doit pouvoir être modifié facilement pour s'adapter à de nouveaux besoins.
- **Testable :** Il doit être possible de vérifier son bon fonctionnement à travers des tests.
- **Documenté :** Il doit être accompagné de commentaires ou de documentation pour faciliter sa compréhension.
- **Sécurisé :** Il doit être conçu pour éviter les erreurs ou les comportements indésirables.
- **Évolutif :** Il doit pouvoir être amélioré ou étendu sans nécessiter une refonte complète.
- **Indépendant :** Il doit être conçu de manière à minimiser les dépendances externes.
- **Robuste :** Il doit pouvoir gérer les erreurs ou les situations imprévues de manière appropriée.
- **Consistant :** Il doit produire les mêmes résultats pour les mêmes entrées à chaque exécution.
- **Portabilité :** Il doit pouvoir être exécuté sur différentes plateformes ou environnements.

# Types d'algorithmes

Il existe plusieurs types d'algorithmes, chacun adapté à des tâches spécifiques. Quelques exemple :
- **Algorithmes de tri :** Utilisés pour organiser des données (ex. : tri à bulles, tri rapide).
- **Algorithmes de recherche :** Utilisés pour trouver des éléments dans des structures de données (ex. : recherche binaire, recherche linéaire).
- **Algorithmes de graphes :** Utilisés pour résoudre des problèmes liés aux graphes (ex. : Dijkstra, A*).
- **Algorithmes de cryptographie :** Utilisés pour sécuriser les communications (ex. : RSA, AES).
- **Algorithmes de compression :** Utilisés pour réduire la taille des données (ex. : Huffman, LZW).
- **Algorithmes de machine learning :** Utilisés pour l'apprentissage automatique (ex. : k-means, réseaux de neurones).
- **Algorithmes de backtracking :** Utilisés pour résoudre des problèmes combinatoires (ex. : Sudoku).
