# Advent of Code 2016 - Jour 1

> **Lien du défi :** [Advent of Code 2016 - Day 1](https://adventofcode.com/2016/day/1)  
> **Documentation utile :** [explode() en PHP](https://www.php.net/manual/fr/function.explode.php), [substr() en PHP](https://www.php.net/manual/fr/function.substr.php)

## Contexte du problème
Vous démarrez aux coordonnées `(0, 0)` en faisant face au **Nord**.  
Une suite d'instructions vous indique comment vous déplacer :
- Une lettre d'orientation : `R` (tourner à droite de 90°) ou `L` (tourner à gauche de 90°).
- Un nombre de blocs à parcourir en ligne droite (ex: `R4` = tourner à droite puis avancer de 4 blocs).

**Objectif :** Calculer la **distance** (distance en blocs de ville) entre le point de départ et le point d'arrivée :  
$$\text{Distance} = |x| + |y|$$

---

## Approche 1 : Gestion des directions par points cardinaux ("N", "E", "S", "W")

Dans cette version, la direction est stockée sous forme de lettre (`"N"`, `"E"`, `"S"`, `"W"`).  
Chaque virage fait pivoter la boussole vers le point cardinal suivant.

```php
<?php  
// Chaîne d'instructions fournie par le défi
$input = "R4, R4, L1, R3, L5, R2, R5, R1, L4, R3, L5, R2, L3, L4, L3, R1, R5, R1, L3, L1, R3, L1, R2, R2, L2, R5, L3, L4, R4, R4, R2, L4, L1, R5, L1, L4, R4, L1, R1, L2, R5, L2, L3, R2, R1, L194, R2, L4, R49, R1, R3, L5, L4, L1, R4, R2, R1, L5, R3, L5, L4, R4, R4, L2, L3, R78, L5, R4, R191, R4, R3, R1, L2, R1, R3, L1, R3, R4, R2, L2, R1, R4, L5, R2, L2, L4, L2, R1, R2, L3, R5, R2, L3, L3, R3, L1, L1, R5, L4, L4, L2, R5, R1, R4, L3, L5, L4, R5, L4, R5, R4, L3, L2, L5, R4, R3, L3, R1, L5, R5, R1, L3, R2, L5, R5, L3, R1, R4, L5, R4, R2, R3, L4, L5, R3, R4, L5, L5, R4, L4, L4, R1, R5, R3, L1, L4, L3, L4, R1, L5, L1, R2, R2, R4, R4, L5, R4, R1, L1, L1, L3, L5, L2, R4, L3, L5, L4, L1, R3";  

// Découpage de la chaîne en tableau d'instructions individuelles
// ex: ["R4", "R4", "L1", "R3", ...]
$instructions = explode(", ", $input);  

// Coordonnées initiales sur le repère cartésien
$x = 0;  
$y = 0;  

// Direction initiale : face au Nord
$direction = "N";  

foreach ($instructions as $instruction) {  
    $tourne = $instruction[0]; // Premier caractère : 'R' ou 'L'

    // 1. Mise à jour de l'orientation selon le virage
    if ($tourne == "R") {  
        // Tourner à droite (sens horaire : N -> E -> S -> W -> N)
        if ($direction == "N")      $direction = "E";  
        elseif ($direction == "E") $direction = "S";  
        elseif ($direction == "S") $direction = "W";  
        elseif ($direction == "W") $direction = "N";  
    }  

    if ($tourne == "L") {  
        // Tourner à gauche (sens anti-horaire : N -> W -> S -> E -> N)
        if ($direction == "N")      $direction = "W";  
        elseif ($direction == "E") $direction = "N";  
        elseif ($direction == "S") $direction = "E";  
        elseif ($direction == "W") $direction = "S";  
    }  

    // 2. Extraction du nombre de blocs à parcourir
    // IMPORTANT : On utilise substr($instruction, 1) pour récupérer TOUS les chiffres,
    // car certaines valeurs font 2 ou 3 chiffres (ex: "L194" -> 194, "R49" -> 49).
    $distance = (int) substr($instruction, 1);

    // 3. Déplacement sur la grille
    if ($direction == "N") $y += $distance; // On monte (+y)  
    if ($direction == "S") $y -= $distance; // On descend (-y)  
    if ($direction == "E") $x += $distance; // On va à droite (+x)  
    if ($direction == "W") $x -= $distance; // On va à gauche (-x)  
}  

// 4. Calcul de la distance : |x| + |y|
// Note : les parenthèses sont indispensables pour éviter les soucis de priorité entre '.' et '+'
$distance = abs($x) + abs($y);

echo "Position finale : x = $x, y = $y" . PHP_EOL;
echo "Distance : " . $distance . " blocs" . PHP_EOL;
```

## Approche 2 : Version en degrés (comme en navigation ou aéronautique)

Cette approche remplace les tests de chaînes par un calcul arithmétique d'angle (un **cap**) :
- `0°` : Nord
- `90°` : Est
- `180°` : Sud
- `270°` : Ouest

```php
<?php  
$input = "R4, R4, L1, R3, L5, R2, R5, R1, L4, R3, L5, R2, L3, L4, L3, R1, R5, R1, L3, L1, R3, L1, R2, R2, L2, R5, L3, L4, R4, R4, R2, L4, L1, R5, L1, L4, R4, L1, R1, L2, R5, L2, L3, R2, R1, L194, R2, L4, R49, R1, R3, L5, L4, L1, R4, R2, R1, L5, R3, L5, L4, R4, R4, L2, L3, R78, L5, R4, R191, R4, R3, R1, L2, R1, R3, L1, R3, R4, R2, L2, R1, R4, L5, R2, L2, L4, L2, R1, R2, L3, R5, R2, L3, L3, R3, L1, L1, R5, L4, L4, L2, R5, R1, R4, L3, L5, L4, R5, L4, R5, R4, L3, L2, L5, R4, R3, L3, R1, L5, R5, R1, L3, R2, L5, R5, L3, R1, R4, L5, R4, R2, R3, L4, L5, R3, R4, L5, L5, R4, L4, L4, R1, R5, R3, L1, L4, L3, L4, R1, L5, L1, R2, R2, R4, R4, L5, R4, R1, L1, L1, L3, L5, L2, R4, L3, L5, L4, L1, R3";  

$instructions = explode(", ", $input);  

$x = 0;  
$y = 0;  

// Cap initial : 0° = Nord
$direction = 0;   

foreach ($instructions as $instruction) {  
    // 1. Rotation par calcul d'angle avec modulo 360°
    if ($instruction[0] == "R") {
        // Tourner à droite : +90°
        $direction = ($direction + 90) % 360;  
    }

    if ($instruction[0] == "L") {
        // Tourner à gauche : équivaut à -90°, soit +270° modulo 360.
        // ASTUCE : En PHP, (-90) % 360 renverrait -90 (résultat négatif !).
        // Faire (+ 270) garantit un résultat toujours positif compris entre 0 et 359.
        $direction = ($direction + 270) % 360;  
    }
  
    // 2. Extraction de la distance
    $distance = (int) substr($instruction, 1);  

    // 3. Déplacement selon l'angle actuel
    if ($direction == 0)   $y += $distance; // Nord
    if ($direction == 90)  $x += $distance; // Est
    if ($direction == 180) $y -= $distance; // Sud
    if ($direction == 270) $x -= $distance; // Ouest
}  

$distance = abs($x) + abs($y);

echo "Position finale : x = $x, y = $y" . PHP_EOL;
echo "Distance : " . $distance . " blocs" . PHP_EOL;
```

## Points clés à retenir pour les étudiants

1. **Extraction de sous-chaînes :**  
   `$instruction[1]` n'accède qu'au 2ème caractère de la chaîne. Dès qu'un nombre comporte plusieurs chiffres (`194`, `49`, etc.), il faut utiliser `substr($instruction, 1)` pour récupérer l'intégralité du nombre.
2. **L'opérateur modulo `%` avec les négatifs :**  
   En PHP, `(-90) % 360` vaut `-90` et non `270`. Pour reculer d'un quart de tour sur un cercle de 360°, ajouter `270` (ou faire `($valeur - 90 + 360) % 360`) évite d'obtenir un angle négatif.
3. **Priorité des opérateurs (`.` vs `+`) :**  
   Toujours entourer les opérations arithmétiques de parenthèses `(...)` lors d'une concaténation dans un `echo`.
